# 비공개 파일럿 기기 등록

팀원·멘토는 초대 코드로 처음 한 번 기기를 등록합니다. 회원 계정 로그인과는 별개이며, 서버 재배포나 동일 서명 APK 업데이트로 앱 데이터가 유지되면 재등록하지 않습니다. 재설치·앱 데이터 삭제·새 기기·자격 만료/취소 시 다시 등록합니다.

## 실행 모드

- 기본/`local`: 기존 개발 환경과 API 계약을 유지합니다. 공개 또는 여러 사용자 환경에 쓰지 않습니다.
- `pilot`: `/api/installations/enroll`을 제외한 모든 `/api/*` 요청에 설치별 `Authorization: Bearer <token>`이 필요합니다. 공용 `X-App-Api-Key`는 인증 수단이 아닙니다.
- 배포 DB와 함께 실행: `SPRING_PROFILES_ACTIVE=postgres,pilot`. `postgres`는 Flyway와 스키마 검증을 사용합니다. `local`과 함께 지정하지 않습니다.
- 초대 코드는 만료와 사용 횟수를 가진 공유 초대장입니다. 매번 사람이나 기기를 관리자가 수동 등록하지 않습니다. 기기는 초대 코드 사용 시 서버에서 새로운 설치 ID와 토큰을 받습니다.

파일럿 모드에서 서버는 설치 ID를 토큰으로 결정합니다. `X-Installation-Id`를 생략해도 되며, 보내면 인증된 설치 ID와 일치해야 합니다. 다른 설치 ID를 보내면 403입니다. 사진 목록·내용·라벨·위치·분석·다량 분석·편집·장소·누적 기록과 참조 입력 모두 소유권 검사를 적용합니다. 타인 또는 소유자 없는 이전 사진은 404로 처리합니다. 기존 공유 데이터를 새로 등록한 첫 기기에 자동 배정하지 않습니다.

## 요청·응답

```http
POST /api/installations/enroll
Content-Type: application/json

{"inviteCode":"ABCD-EFGH-IJKL-MNOP-QRST"}
```

```json
{
  "installationId":"11111111-1111-4111-8111-111111111111",
  "token":"<기기에만 보관할 비밀 토큰>",
  "expiresAt":"2027-05-08T00:00:00Z"
}
```

응답은 201, `Cache-Control: no-store`입니다. 토큰 원문은 등록 응답에만 나오며 로그·스크린샷·이슈·빌드 설정에 기록하지 않습니다. 서버는 SHA-256 해시만 보관합니다. 초대 코드도 해시만 DB에 보관합니다. 설치 자격은 발급 시점부터 180일간 유효합니다.

```http
GET /api/installations/current
Authorization: Bearer <등록 응답 token>
```

200 `{"installationId":"11111111-1111-4111-8111-111111111111"}`이면 사용할 수 있습니다. 이후 기존 API 경로와 JSON은 그대로 쓰고 같은 Bearer 헤더를 추가합니다.

- 401 `PILOT_REGISTRATION_REQUIRED`: 등록되지 않았거나 자격 만료·취소. 새 초대 코드로 등록합니다.
- 403 `INVALID_INVITE`: 코드가 없거나 만료·사용 횟수 소진. 원인을 세분화해 노출하지 않습니다.
- 403 `INSTALLATION_MISMATCH`: 헤더의 ID가 인증된 기기와 다릅니다.
- 404: 사진이나 작업이 없거나 현재 설치에서 접근할 수 없습니다.
- 429 `ENROLLMENT_RATE_LIMITED`: 같은 접속 주소에서 1분 동안 10회를 넘겨 등록을 시도했습니다. 잠시 기다립니다. 클라이언트의 전달 IP 헤더는 신뢰하지 않습니다. 한 프록시 뒤에서는 제한을 공유하므로 파일럿보다 큰 규모에는 공유 저장소 기반 제한이 필요합니다.

## 초대 발급과 취소 — 운영자만

기존 PostgreSQL에 접속 가능한 환경에서 libpq의 `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`와 비공개 `.pgpass` 또는 `PGPASSFILE`을 설정합니다. 비밀번호를 명령 인자에 넣지 않습니다. 아래 명령은 실제 DB를 변경하므로 현재 배포 준비 단계에서 운영 AWS에 실행하지 않습니다.

```sh
python3 deploy/tools/create_invite.py --uses 10 --days 7 --output private-data/invite.txt
```

코드는 지정 파일에만 0600 권한으로 기록됩니다. 파일은 Git에서 제외됩니다. 비공개 채널로 전달하고 전달 후 파일을 삭제합니다. 기존 파일은 덮어쓰지 않습니다.

초대장을 취소하려면 해당 해시의 `remaining_uses`를 0으로 갱신합니다. 설치 자격을 취소하려면 운영자 DB 접속에서 다음을 실행합니다. 대상 설치 UUID를 확인하고 사용하며, 모든 기기를 지우는 명령은 아닙니다.

```sql
update pilot_installations set revoked = true
where id = '11111111-1111-4111-8111-111111111111';
```

취소는 다음 API 요청부터 적용됩니다. 기존 사진·기록을 자동 삭제하지 않습니다. 기기를 잃어버렸을 때는 해당 설치를 취소하고, 데이터 이관은 운영자가 별도 검토합니다. 현재는 기기 간 계정 동기화나 자격 복구 기능을 제공하지 않습니다.

## 검증 경계

로컬 합성 사진과 명시적 stub 분석·편집으로 두 설치의 접근 분리와 등록 실패를 확인합니다. 실제 AWS·실제 AI 호출이나 실제 사진을 사용한 결과와 구분합니다. 외부 접속은 HTTPS로 제공해야 하며, AWS 계정 연결 후 실제 도메인·권한·기기 네트워크를 별도 검증합니다.
