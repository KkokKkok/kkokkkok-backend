이전 결과 내 컴퓨터에서만 실행

1단계

사진과 분석 결과를 준비해요

텍스트 방식은 영역 찾기에 사진을 사용하고, 편집 실행 시 사진과 mask를 선택한 모델로 보냅니다. 입력과 결과는 저장소가 아닌 Downloads에 저장됩니다.

수정 영역 지정 방식

모의 분석 결과 단서를 등록하세요

분석 결과에 들어올 설명·위험도·근거를 입력하고, 사진에서 위치를 드래그해 주세요. 여기 입력한 값은 테스트용이며 확정된 API 형식이 아닙니다.

각 영역을 편집 대상으로 선택하면 선택한 곳만 한 번의 편집 요청으로 보냅니다. 좌표는 EXIF 방향 보정 사진 기준으로 저장합니다.

사진을 선택하면 여기에 표시됩니다.
